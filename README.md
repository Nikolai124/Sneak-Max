### Sneak Max
**Сайт по продаже кроссовок**

_Для локального запуска проекта требуется:_

1. Установить Python 3
2. Разрешить виртуализацию для терминала(в интернете много гайдов для этого)
3. Ввести команды: 
`pip install -r requirements.txt`
`./venv/Scripts/activate`
`flask --app app run`
4. Перейти по ссылке на локальный сервер в терминале

_Цель проекта_

Код написан в образовательных целях для лучшего понимания разработки сайта, разработчиками являются Elisey0000(frontend) и Nikolai124(backend)
